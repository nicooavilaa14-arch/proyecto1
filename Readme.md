## 📌Description

 Este proyecto consiste en una pagina wed de un blog promocionando viajes globales
 solo utilizando HTML y CSS. El objetivo es promocionar y mostrar distintas partes
 del mundo de una manera orgánica y atractiva

 ## 🛠️Tecnologías y Extensiones utilizadas

   -HTML
   -CSS
   -LIVE SERVER 

## ✈️Características

  -paginas con diseño responsive 
  -una galería con imágenes de lugares turísticos
  -navbar fijo y completamente funcional 
  -error 404 en links inválidos
